# The Interview — браузерная реконструкция гаражного теста из Driver (1999)

Фанатская учебная реконструкция первой миссии Driver: You Are the Wheelman.
Один уровень: подземный гараж, 60 секунд, 9 манёвров, четвёртый удар — провал.
Вся графика, звук и машины сделаны с нуля (процедурные текстуры, Web Audio).
Репозиторий: https://github.com/Alex-Dovgopoly/driver-game, ветка `main`.

## Контекст оригинала

- **Игра:** Driver (1999), Reflections Interactive / GT Interactive, PS1, позже PC.
  Геймдизайнер Мартин Эдмондсон. Атмосфера — автомобильные боевики 70-х.
- **Сюжет:** Джон Таннер, детектив NYPD и бывший гонщик, внедряется в синдикат
  Кастальди. Четыре города: Майами → Сан-Франциско → Лос-Анджелес → Нью-Йорк.
- **Миссия «The Interview»:** первая и единственная обучающая. Заброшенный
  многоуровневый паркинг в Майами, потенциальные работодатели из криминала
  смотрят, как Таннер показывает навыки. Сцена напрямую взята из фильма
  «Водитель» (The Driver, 1978, Уолтер Хилл) — там герой Райана О'Нила
  разносит машину в гараже, чтобы доказать, что он лучший.
- **Правила оригинала:** секундомер на 60 с, список манёвров справа сверху,
  выполненный зачёркивается красной линией. Каждый контакт с машиной, стеной
  или колонной — красный ✕ над списком; четвёртый — провал. Порядок любой.
- **Управление в оригинале (PS1):** ✕ газ, □ тормоз/задний ход, △ ручник,
  ○ бёрнаут, L1 — блокировка колёс в сторону поворота. Машины склонны
  к недостаточной поворачиваемости, ручник и бёрнаут — ключ ко всем трюкам.
- **Репутация:** одна из самых сложных «обучалок» в истории PS1, многие
  игроки дальше неё не прошли. Льюис Хэмилтон, по его словам, тоже мучился.
  Тест переделан как пасхалка в Driver: San Francisco (2011): найти DeLorean
  и разогнаться до 88 миль/ч.

## Девять манёвров

Названия и порядок — как в оригинале. Правая колонка — наша детекция
(`src/game/maneuvers.js`). Скорости внутри кода в м/с, в HUD — км/ч.

| # | Манёвр | В оригинале | Наша детекция |
|---|--------|-------------|---------------|
| 1 | Burnout | нажать ○ на месте | `car.spin` (Shift при скорости < 6 м/с, без ручника) дольше 0.8 с |
| 2 | Handbrake | дёрнуть △ | ручник при ≥ 45 км/ч |
| 3 | Slalom | змейка между колоннами | пересечь 4 колонны одного ряда подряд, чередуя сторону, потом то же обратно (`½` в HUD после первой половины) |
| 4 | 180° | руль до упора + ручник | за ≤ 2.4 с рыскание ≥ 0.88π при входной vL > 6 м/с и ручнике в последние 2.4 с |
| 5 | 360° | руль до упора + бёрнаут, полный круг | за ≤ 3.6 с рыскание ≥ 0.95·2π |
| 6 | Reverse 180° | задним ходом на полной, руль до упора | за ≤ 2.8 с рыскание ≥ 0.85π при входной vL < −4 м/с |
| 7 | Speed | максимальные обороты (~50 mph) | ≥ 80 км/ч вперёд |
| 8 | Brake test | тормоз (+ручник) с высокой скорости | тормоз без ручника с ≥ 55 км/ч до < 1.5 км/ч, не дольше 5 с |
| 9 | Lap | круг по внешнему периметру | накопленный угол вокруг центра ≥ 2π; обнуляется при заезде в центральную зону (|x| < 32.5, |z| < 9) |

Удар засчитывается при нормальной скорости столкновения ≥ 2.2 м/с и не чаще
раза в 0.9 с. В тренировке удары считаются, но не выгоняют.

## Архитектура

Vite + `three@0.128.0` (ES-модули). Исходный прототип — `interview.html`
в корне, один файл с CDN three r128. Он хранится как референс, не правится:
порт должен вести себя один в один с ним.

```
index.html / style.css   — разметка HUD, меню, результата, тач-кнопок; стили
src/main.js              — renderer/scene/camera, state machine, камера, главный цикл
src/game/state.js        — общее состояние: mode, lastMode, muted, camMode, shake
src/game/maneuvers.js    — MAN (9 манёвров), createManeuvers(): детекция, удары, прогресс
src/physics/car.js       — car {x,z,th,vx,vz,w,steer,...}, resetCar, physStep(dt, inputs, onHit)
src/physics/collide.js   — obstacles (AABB в плоскости XZ), addBox, collide(car, onHit)
src/world/constants.js   — GW×GD = 100×44 м, CEIL 4.6, ROWS, PX, START
src/world/textures.js    — makeCanvas, texFrom, speckle, blotches (процедурные канвасы)
src/world/garage.js      — buildGarage(scene): пол, стены, декали, колонны, потолок, свет
src/world/cars.js        — makeCar, placeParkedCars, createPlayer (фара-спот)
src/fx/smoke.js          — пул из 90 спрайтов дыма
src/fx/skids.js          — InstancedMesh следов шин (кольцевой буфер 1400)
src/fx/suspension.js     — визуальная подвеска: пружина с демпфером для клевка и крена кузова
src/audio.js             — процедурный двигатель, визг, blip, thud
src/ui/hud.js            — таймер, спидометр, список манёвров, ✕, тосты
src/ui/menu.js           — оверлеи меню и результата, кнопки
src/ui/input.js          — Set кодов клавиш + touchK, readInputs(live)
src/ui/touch.js          — тач-кнопки (body.touch при pointer: coarse)
```

**Режимы** (`state.mode`): `menu` → `count` (3-2-1) → `play` → `over`;
`train` — без таймера. R перезапускает текущий режим, Esc в меню,
Enter — старт из меню или повтор с экрана результата, C — камера, M — звук.

**Цикл:** физика фиксированным шагом 1/120 с (аккумулятор), ввод снимается
раз в кадр, dt кадра обрезан до 0.05 с. Манёвры и таймер считаются
на кадровом dt, только в `play`/`train`.

**Координаты:** гараж в плоскости XZ, длинная ось — X (±50), короткая — Z
(±22). `car.th` — курс в радианах, ось X = 0; для three берётся
`rotation.y = -car.th`. Коллизии: три окружности радиуса 0.98 вдоль
оси машины (±1.55, 0) против AABB-препятствий, два прохода.

**Связи между модулями:** `maneuvers` импортирует `hud`, `audio`, `state`,
`car`; `main` отдаёт в `createManeuvers` колбэк `onFinish`. `hud`
и `menu` ничего игрового не импортируют и получают `MAN` параметром —
это держит граф без циклов.

## Соглашения

- Поведение прототипа — эталон. Любая правка физики, порогов детекции
  или таймингов делается осознанно и обсуждается, а не «по пути».
- `three` запинен на 0.128.0. В новых версиях иные color space
  (`outputEncoding` → `outputColorSpace`) и физически корректный свет,
  картинка и яркость уйдут. Апгрейд — отдельная задача с перенастройкой
  интенсивностей.
- Текст интерфейса — русский, названия манёвров — английские, как в HUD
  оригинала.
- Числа внутри физики в м/с и радианах, в UI — км/ч. Не смешивать.
- Новые модули — внутрь существующих папок (`fx/`, `ui/`, `world/`…).

## Команды

```
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm run preview
```

Проверка в браузере: вкладка должна быть видимой — в фоновой вкладке
`requestAnimationFrame` замирает, и игра стоит (так и в прототипе).
Ввод можно эмулировать `KeyboardEvent` с нужным `code` на `window`.
